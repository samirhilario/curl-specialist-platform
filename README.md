# Curl Specialist Platform

A Phase 1 client and product tracking dashboard for a curl specialist.

## Features
- Dashboard layout
- Client list
- Add client form
- Client profile pages
- Add/remove products used
- Edit curl type, porosity, and notes
- Responsive layout

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- React state management

## Phase 1 Status
Frontend MVP complete using mock data and in-memory state.
